# User Registration & Authentication — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan.

**Goal:** Implement phone+SMS registration, password login with JWT, token refresh, and logout. WeChat OAuth deferred (needs WeChat app registration). SMS uses a mock provider for now (Alibaba Cloud SMS integration deferred).

**Architecture:** Services layer handles business logic. API layer handles HTTP. Passwords hashed with bcrypt via passlib. JWT access tokens (30min) + refresh tokens (7 days) via python-jose. SMS codes stored in Redis with 5-minute TTL. All endpoints follow `/api/auth/*` prefix.

**Tech Stack:** passlib[bcrypt], python-jose, redis, FastAPI

---

## Task 1: Auth Service

**Create `backend/app/services/auth.py`**

Functions:
- `hash_password(password: str) -> str` — bcrypt hash
- `verify_password(password: str, hash: str) -> bool`
- `create_access_token(user_id: str) -> str` — JWT with 30min expiry
- `create_refresh_token(user_id: str) -> str` — JWT with 7 day expiry
- `decode_token(token: str) -> dict | None` — decode and validate JWT

## Task 2: SMS Service

**Create `backend/app/services/sms.py`**

Mock SMS provider. Functions:
- `generate_code() -> str` — 6-digit random code
- `send_code(phone: str, code: str)` — stores code in Redis with 5min TTL (mock: prints to console)
- `verify_code(phone: str, code: str) -> bool` — checks against Redis

## Task 3: Auth Schemas

**Create `backend/app/schemas/auth.py`**

Pydantic models:
- `SendCodeRequest(phone: str)`
- `VerifyCodeRequest(phone: str, code: str)`
- `RegisterRequest(phone: str, password: str, code: str)` — password min 8 chars
- `LoginRequest(phone: str, password: str)`
- `RefreshRequest(refresh_token: str)`
- `TokenResponse(access_token: str, refresh_token: str, token_type: str = "bearer")`
- `UserResponse(id: str, phone: str | None, role: str, created_at: str)`

## Task 4: Redis Client

**Create `backend/app/core/redis.py`**

Redis client wrapper using the redis package:
```python
import redis
from app.core.config import settings

r = redis.from_url(settings.redis_url, decode_responses=True)
```

## Task 5: Auth API Endpoints

**Create `backend/app/api/auth.py`**

Endpoints:
- `POST /api/auth/send-code` — send SMS verification code
- `POST /api/auth/register` — verify code + create user + grant free credits + return tokens
- `POST /api/auth/login` — verify phone+password, return tokens
- `POST /api/auth/refresh` — exchange refresh token for new access token
- `POST /api/auth/logout` — invalidate refresh token
- `GET /api/auth/me` — get current user profile (requires auth)

## Task 6: Auth Dependency

Create `backend/app/api/deps.py` with `get_current_user` FastAPI dependency (extracts and validates JWT from Authorization header).

## Task 7: Register Router

Update `backend/app/main.py` to include the auth router.
